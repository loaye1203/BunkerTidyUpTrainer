# Bunker Tidy Up Trainer 1.0.1

此更新将自动吸取扩展至 15 级，并新增 Carry 21 级。磁铁 11–15 级分别吸取 60/70/80/90/100 件，冷却 14/13/12/11/10 秒，逐件处理间隔仍为 0.05 秒。Carry 21 不增加容量（仍为 270），每次正常点击同步拾取鼠标瞄准点附近最多 10 件，首个原版点击计入上限；同一次按住不会重开批次，松开后再次点击可开始下一次。

1.0.1 保留 1.0.0 的原版费用与 4,076 星总预算。新增等级费用按等级不递减：携带 1,154、自动吸取 659、各归其位 718、连续放置 265 星，合计 2,796 星；渐进奖励曲线继续以 44 星封顶。已有存档保留实际购买等级，不退款、不追补历史奖励；新档仅在从第一种物资起始终启用“更多星星”时保证奖励覆盖全升级费用。

桌面安装程序可将管理标记为 1.0.0 的已有用户级安装更新到 1.0.1，并继续保留游戏配置。请在游戏完全退出时通过控制器安装/更新游戏插件；不需要控制器常驻。

详细行为与验收范围见 `README.md` 和 `验证报告.md`。本工具只支持 Windows x64、Unity Mono 6000.0.59f2 与 BepInEx 5.4.23.5；测试驱动模拟按键/瞄准，不代表物理键鼠映射测试。
