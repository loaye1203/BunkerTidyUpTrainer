# Bunker Tidy Up Trainer 1.0.2 验证报告

本报告记录 1.0.2 针对 Carry 等级迁移与真实输入链路的必要验收；1.0.0、1.0.1 历史报告及 Release 均保留。游戏内验收只使用工作区隔离副本与测试槽，没有启动或写入 Owner 的正式游戏和玩家存档。

## 构建与发行包

- 使用 `scripts/Build-Release.ps1`、项目内 .NET 10 SDK、本地 BepInEx 5.4.23.5 包和 Unity 6000.0.59f2 Managed 引用，构建 Windows x64 自包含控制器、Mono 插件、便携 ZIP 与 Setup.exe。编译成功，0 个错误；构建输出含 NuGet 漏洞服务离线的 NU1900 警告及少量既有未使用字段警告。
- 控制器、共享程序集、插件与 Setup 产品版本为 1.0.2，文件版本为 1.0.2.0。便携包包含隐藏文件 `Payload/.doorstop_version`、MIT 许可、第三方声明、中文说明及界面图；Setup 嵌入同一便携包。`SHA256SUMS.txt` 与 `release-metadata.json` 记录两个发行文件的实际校验值。
- 安装器升级测试先通过真实 1.0.1 Setup 建立安装夹具，再运行 1.0.2 Setup `/self-test` 升级。退出码为 0；安装标记从 1.0.1 更新至 1.0.2，回执中 Controller 与 Plugin 均为 1.0.2，已有用户文件 `user-config-sentinel.txt` 保留，安装后的隐藏 Doorstop 标记存在。此测试只覆盖桌面工具安装夹具，不代表正式游戏插件已部署。

## Carry 迁移、真实输入与持续拾取

- 使用与 Carry 21 侧档保存指纹匹配的隔离旧存档执行真实 Continue。匹配的旧侧档原文先归档，再将 Carry 迁移到 16；ItemPull 15、ShelfScatter 6、RepeatInteract 7 保留，Carry 16 的 `Hands.MaxCount` 为 200。游戏 AutoSave 成功提交迁移后的扩展等级，主存档等级维持原版兼容范围。
- phase5 在真实 Unity InputSystem `InteractAction` 上临时覆盖隔离绑定，并通过虚拟 Keyboard 状态事件驱动输入。观察到 InputAction 开始事件、游戏 `DefaultInteractionBehaviour.OnInteractRequested` 的 release-edge 请求，且原 `PickableItem.TryInteract` 执行时 `IsPressed=false`。原绑定 `<Mouse>/leftButton` 仅在隔离进程中临时映射为 `<Keyboard>/e`；首件后的瞄准点由 TestMode 夹具提供。
- 首个原版点击后继续按住，生产拾取逻辑从 40 个有限合法候选中额外拾取 35 件，超过旧 30 件单次限制；每帧最多成功一件。Carry 16 的调度目标为 0.0670 秒（14.92992 件/秒），本次 35 件的实测平均间隔为 0.1204 秒（约 8.31 件/秒），低于目标上限。该平均值受全场扫描开销和帧时间影响，不表示达到目标吞吐量。Unity InputSystem 释放事件送入后，0.45 秒观察窗口内未继续拾取。
- 首次长样本观测到 0.0554 秒间隔，定位到查询/拾取的运行时间被从下次等待中扣除。代码已将成功拾取完成作为下一间隔的起点，同一 phase5 复测通过；日志检查每次成功间隔不会短于配置节拍容差。初次失败记录仅保留在本地证据目录，没有放入发行包。
- 本次测试的按键由虚拟设备事件驱动，瞄准点由 TestMode 夹具设置，不是物理键鼠重映射或玩家手动试玩；拾取与保存调用的是游戏原方法。没有测试 Owner 存档。

## 数值核对与验证边界

- phase5 运行时核对原版费用 1,280 星、新增费用 2,796 星、总额 4,076 星；读取 `ShelfScoring.TypesCount=136`，奖励总额 4,076，计数边界为 20/21/44/44 星。此项是费用表、奖励计数及游戏保存接口核对，不是整理完 136 种物资的完整通关。
- Carry 8–16 新等级费用为 100/106/112/118/125/132/142/152/167 星，Carry 16 容量 200。ItemPull 11–15 表为 60/70/80/90/100 件、14/13/12/11/10 秒冷却，逐件处理节奏 0.05 秒未改。
- 本次未构造超过 200 件的手持库存，因此没有把 201+ 物品保存、恢复或完整恢复卸载作为 1.0.2 实测通过。实现保留读取保存手持物时临时抬高容量的代码路径；普通 `Hands.CanAdd` 拾取限制仍由原版逻辑执行。未测试其他游戏版本、IL2CPP 或与其他加载器共存。
