# Bunker Tidy Up Trainer 1.0.2

本版将携带容量上限调整为 16 级，容量为 200。携带扩展开启且生效等级达到 10 后，按住原拾取动作即可持续拾取瞄准点附近的合法地面物资；拾取速度按 `5 × 1.2^(等级−10)` 计算，不再按每次按住的物品数封顶。松开输入、失焦、暂停、UI 锁定或容量满时按游戏状态停止或等待。范围拾取仍调用游戏原拾取方法，不改变 V 键自动吸取技能。

从 1.0.0/1.0.1 更新时，匹配当前存档指纹的 Carry 17–21 侧档会先备份再迁移至 16；其他技能等级保留，已花星星不退款。新容量与携带费用适用于本版；旧档已购买等级不补扣费用。1.0.0/1.0.1 的更多星星曲线和 4,076 星新档预算保持不变。

本版修正连续拾取的间隔起点：成功调用游戏拾取并完成后，才开始等待下一间隔，避免场景搜索或游戏拾取耗时导致实际速度超过等级目标。携带以外的技能、掉落及其他控制器行为保持原有版本数值。

桌面安装器可升级标记为 1.0.0 或 1.0.1 的本工具用户级安装，并保留游戏配置。正式游戏插件更新应在游戏完全退出后通过控制器安装；本版验证使用隔离游戏副本，不修改玩家存档。

完整操作说明、兼容条件及本版验证边界见 `README.md` 与 `验证报告.md`。
