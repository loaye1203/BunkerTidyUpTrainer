# Bunker Tidy Up Trainer 1.0.0 验证报告

此报告概括当前首发版本的构建、隔离运行与安装器证据。原始本地测试日志、玩家存档和私人计算机路径不随公开源码或发行包发布。

## 构建和插件加载

- 游戏插件以 Release / `netstandard2.1` 构建通过，控制器以 Windows x64 / .NET 10 自包含单文件发布。
- 在 Bunker Tidy Up Unity 6000.0.59f2 Mono、BepInEx 5.4.23.5 隔离进程中，插件成功加载并绑定 36 个 Harmony 目标。
- 隔离测试启用测试模式拦截成就写入；功能测试不写入玩家 Steam 成就。
- 主界面 WPF 预览使用应用内 `RenderTargetBitmap` 导出并检查。公开图片见 `docs/assets/trainer-ui.png`。

## 游戏行为证据

- 扩展表、真实购买等级、临时升满与扩展开关保留购买等级通过隔离存档验证；临时升满没有写入真实购买记录。
- 无限星星调用真实游戏消费方法验证免消费、实际余额不变。更多星星核验了 `ScoredTypes` 计数为 68 时的奖励档位为 21 星，并通过原游戏 `GetSaveData` / `LoadFromSaveData` 保存读取；没有声称完整整理 136 种物资。
- Carry 20 容量 270；关闭携带扩展时等级与容量恢复原版 7 级 / 75。扩展关闭后的超容量 Continue 实测恢复 106 件，普通 `Hands.CanAdd` 拒绝更多物品。完整卸载在超容量或记录不完整时被拦截。
- 按住范围拾取由隔离 TestMode 模拟按住和瞄准，调用游戏原 `PickableItem.TryInteract`、`PlayerInteractor.TryPick`；检查范围拾取各档上限、按当前瞄准点重新选最近合法目标、松开停止、满上限后不自动重开，并验证 V 风格技能拾取不触发范围拾取。输入由测试驱动提供，未验证物理键盘/鼠标按键映射。
- 携带等级 10/16/17/18/19/20 对应计划间隔 250/200/约167/约143/125/100 毫秒。隔离场景实测平均间隔约 315/262/229/206/189/161 毫秒，逐档观测逐步加快；游戏帧率与测试驱动移动目标带来额外延迟，实测值不等于保证的每秒吞吐。
- 按住连续丢弃配置间隔 125 毫秒，调用游戏原 `OnDropKeyPressed` / `TryDrop` 路径；重复丢弃平均间隔约 131 毫秒。松开后库存停止变化。按住输入以测试驱动模拟，未验证物理键盘按键映射。
- 仅空闲技能 Tick 清除冷却已实测；释放中的互斥与逐件节奏由代码路径核查。

## 安装器与存档保护

- 本次首发 1.0.0 发行脚本完成控制器、插件、便携 ZIP 和自解压安装器构建；源码构建 0 警告、0 错误。安装器程序集、控制器与插件文件版本均为 1.0.0。
- 最终 Setup.exe 在隔离工作区目录执行 `/self-test` 返回 0，报告控制器、插件 1.0.0 和 BepInEx 5.4.23.5；解包后的控制器以 `--render-preview` 启动并返回 0，成功导出界面 PNG。

- 隔离假游戏目录的安装、缺失工具文件修复、恢复移除和二次安装往返通过；用户新增/修改文件由哈希检查保护。
- 多槽恢复测试覆盖另一存档有超容量库存、侧档指纹不符和容量元数据缺失时拒绝卸载；删除槽位可安全跳过。
- 正式游戏文件与玩家存档的历史哈希在开发验收中保持不变；本次首发打包流程不会部署到用户游戏目录。

## 未覆盖范围

- 未在真实玩家存档上完成 136 种物资的完整整理奖励流程。
- 按住拾取和丢弃使用隔离驱动模拟动作/瞄准；键鼠物理映射没有单独实测。
- 公开版本面向 Windows x64、Unity Mono 6000.0.59f2；其他游戏版本、IL2CPP 或与其他加载器共存未经验证。

本报告只陈述上述观察范围，不将静态代码检查、隔离模拟或预算计算描述成未执行的实际游戏操作。
