# Bunker Tidy Up Trainer 1.0.3

本版解决游戏目录已有 `winhttp.dll`、但本工具安装记录丢失时被一律拦截的问题。退出游戏后，点击“安装 / 检查”即可识别兼容加载器或旧版残留、备份相关文件、补齐缺失项并重建安装记录，无需手动删除 DLL 或重装游戏。已有开关配置和扩展等级记录保留。

自动修复支持当前发行包对应的原样 Doorstop 4.5.0/BepInEx 5.4.23.5，以及公开发布的 1.0.0–1.0.2 本工具插件。兼容的已有 Doorstop 配置和其他插件保留；正确入口被禁用时，仅在备份后启用入口。共享加载器不会随本工具卸载而删除；已识别的本工具旧插件也不会在卸载后复活。

无法确认兼容的代理、其他加载器或修改过的文件仍不覆盖，并给出明确提示。支持复用加载器不表示任意其他模组的游戏行为均已测试。游戏技能、数值、星星预算和存档协议未改；操作说明见 README。

安装恢复测试及发行构建由 GitHub Actions 在发布前运行。历史版本与验证报告保留。
