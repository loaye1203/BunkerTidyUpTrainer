# Bunker Tidy Up Trainer 1.0.4

本版适配游戏 10 月 23 日更新（Steam Build 26103693），修复读档补丁误拦截新版笔记、游玩统计及结局恢复入口的问题。技能和升级等级恢复现在只处理对应控制器，并补充空值与类型检查，避免统计字典混入扩展等级记录。

内部存档回读测试支持新版 `Load(Int32)`，同时保留旧版接口后备；新增模式选择与 Continue 参数也已适配。

已用新版游戏实际验证常规模式、简单模式的数据保存读取，以及 New Game+ 的扩展等级和笔记继承、点数清零。功能、界面及修改器数值保持原样；简单模式沿用自身原版数据，本版不重做其奖励预算平衡。

## 下载与升级

- `BunkerTidyUpTrainer-1.0.4-Setup.exe`：Windows 安装程序。
- `BunkerTidyUpTrainer-1.0.4-Portable.zip`：完整解压后使用的便携包。

**升级后请完全退出游戏，在新版控制器中选择原游戏目录，点击「安装 / 检查」更新游戏插件。** 已有配置和扩展记录按安装流程保留，仅更新桌面程序不足以替换游戏插件。

测试范围与证据说明见仓库的 [1.0.4 验证报告](https://github.com/loaye1203/BunkerTidyUpTrainer/blob/main/docs/验证报告-1.0.4.md)。
