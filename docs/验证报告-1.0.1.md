# Bunker Tidy Up Trainer 1.0.1 验证报告

本报告记录 1.0.1 的针对性隔离验收。未重跑与本次变更无关的完整功能套件；原始 1.0.0 报告保留在 `验证报告-1.0.0.md`。本机隔离游戏日志保存在 `.tools/test-evidence/`，不包含在公开发行包中。

## 构建

- 使用仓库 `scripts/Build.ps1` 和项目内 .NET 10 SDK 编译控制器与插件，目标为 Windows x64 控制器及 `netstandard2.1` Unity Mono 插件；控制器、共享程序集和插件文件版本均为 1.0.1.0，产品版本为 1.0.1。
- 构建通过，0 个错误。NuGet 漏洞数据服务索引不可达产生 NU1900 警告；本地依赖还原与编译均完成。
- 插件在隔离的 Unity 6000.0.59f2 Mono 游戏副本中由 BepInEx 5.4.23.5 加载，绑定 36 个 Harmony 目标。验收不启动或写入 Owner 的正式游戏。

## Phase 1：等级、费用、奖励和存档

- 游戏内实时费用表核对：原版费用 1,280 星，新增等级 2,796 星，合计 4,076 星；读取到 `ShelfScoring.TypesCount=136`，渐进奖励合计 4,076，计数边界返回 20/21/44/44 星。
- 隔离测试通过真实购买路径升至自动吸取 15 级和携带 21 级。MaxAll 临时应用未覆盖真实携带 20 级记录；关闭扩展恢复原版表/等级，再打开恢复真实 20 级。
- 随后真实购买携带 21 级，运行游戏 AutoSave，检查与槽位匹配的扩展记录，并通过游戏 `SaveSystem.Load` 读回；原版存档中的等级保持兼容范围。
- 磁铁 11–15 级实际数据表为 60/70/80/90/100 件及 14/13/12/11/10 秒冷却；Carry 21 容量上限为 270。

## Phase 5：Carry 21 即时拾取

- 在隔离 Continue 存档中由 TestMode 模拟交互输入和瞄准点，实际调用游戏原 `PickableItem.TryInteract` / `PlayerInteractor.TryPick`。
- 一次合法点击同步拾取 10 件（包含原点击物品）；同次按住时的重复点击被阻止，等待后没有后台队列继续拾取。
- V 风格直接调用 `TryPick` 只拾取其指定物品，不触发周围批次。模拟松开再按后，剩余合法目标可开始新的点击批次。
- 这项测试使用测试驱动提供的按住/释放/瞄准状态；没有测试物理键盘、鼠标映射，也没有描述为真实玩家存档试玩。

## 发布包与安装器

- 发布包由 `scripts/Build-Release.ps1` 生成。先以真正的 1.0.0 Setup 建立安装夹具，再由 1.0.1 Setup `/self-test` 升级；进程退出码 0，版本回执为 PASS，控制器与插件文件版本均为 1.0.1。升级夹具中的既有用户文件保留。安装后控制器 `--render-preview` 返回 0 并导出界面 PNG。
- 便携 ZIP 包含隐藏的 `Payload/.doorstop_version`、插件、控制器、许可、中文说明和本报告。Setup 与 Portable ZIP 的 SHA-256 列于发行目录 `SHA256SUMS.txt`。
- Setup 仅安装桌面工具。正式游戏目录和玩家存档未由本轮部署修改；用户级插件更新须在游戏退出时通过控制器的事务安装功能执行。

## 未覆盖范围

- 没有逐种整理完 136 种物资；4,076 星是价格/奖励表与新档预算核对，不代表完整通关实测。
- 未测试物理按键映射。动作/瞄准来自隔离测试驱动，但拾取和存档调用游戏原接口。
- 其他游戏版本、IL2CPP 及与其他加载器共存未经验证。
